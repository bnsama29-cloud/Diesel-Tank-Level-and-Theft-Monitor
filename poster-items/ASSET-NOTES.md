# Image asset notes

The images in `assets/` are copies of screenshots and a poster reference image supplied by the project team in chat. They have not been independently captured from a live test during preparation of these poster items.

| Asset | Description | Recommended use |
|---|---|---|
| `reference-image.jpg` | Example academic poster layout | Follow its section order and replace its placeholder content |
| `wokwi-circuit-and-code.png` | Wokwi editor showing code and the ESP32-S2 circuit | System implementation / simulation evidence |
| `dashboard-with-graph.png` | Dashboard with latest values and a fuel-level graph | Dashboard / results illustration |
| `fuel-level-graph.png` | Crop of the graph panel from the supplied dashboard image | Results and discussion graph |

## Evidence caveat

The supplied dashboard image shows a **STALE** status and its explanation refers to older feed points from a previous tank-capacity configuration. The visible graph is an actual screenshot supplied by the team, but it is historical illustration, not evidence that the final cloud setup was live at capture time. Capture a new image after confirming the deployed dashboard displays **LIVE** and current values before using it as final experimental evidence.

The Wokwi screenshot includes the editor and circuit view. Check that the Wokwi project is safe to share and that no private credentials or API keys are visible before printing or publishing it.
