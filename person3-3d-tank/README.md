# Person 3 — Tank visualization

`tank_viewer.html` is a browser-only procedural isometric 3D tank visualization. The dashboard embeds it and substitutes the current `level` feed, so the liquid level follows the Adafruit IO reading. It has no external JavaScript or model dependencies.

## Your part

1. Design the chosen 500 L tank in Onshape.
2. Export a lightweight GLB/GLTF file using Onshape's browser export.
3. The current procedural tank is a complete visualization for integration. If you deliver an Onshape model, replace or extend the viewer to load the GLB/GLTF and clip/scale its liquid mesh using a 0–100 percentage.
4. Keep the viewer's input as a numeric percentage so it remains compatible with the dashboard.
5. Add the model and updated instructions here. Avoid committing very large exports; put oversized files in the team's shared Drive and document the public/read-only link.

The viewer renders a procedural 3D illustration; it is not an exported Onshape CAD model. Building the exact CAD asset requires the team's Onshape design/export and remains a separate deliverable.
