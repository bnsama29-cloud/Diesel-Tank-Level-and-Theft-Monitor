# Person 3 — Tank visualization

`tank_viewer.html` is the initial browser-only isometric tank graphic. The dashboard embeds it and substitutes the current `level` feed, so the liquid moves with the Wokwi slider once the cloud path is working.

## Your part

1. Design the chosen 500 L tank in Onshape.
2. Export a lightweight GLB/GLTF file using Onshape's browser export.
3. Replace or extend the starter tank viewer to load the model and clip/scale the liquid mesh using a 0–100 percentage.
4. Keep the viewer's input as a numeric percentage so it remains compatible with the dashboard.
5. Add the model and updated instructions here. Avoid committing very large exports; put oversized files in the team's shared Drive and document the public/read-only link.

The included graphic is a functional placeholder, not an Onshape model. Do not claim the CAD deliverable is complete until the exported model is integrated and tested.
